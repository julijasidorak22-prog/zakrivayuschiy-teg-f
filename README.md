«Закрывающий тег» — интерактивная страница с анимациями

Страница-манифест с карточками, анимированными иконками «лайка» и диалоговым окном.

Демо: https://julijasidorak22-prog.github.io/zakrivayuschiy-teg-f/

Что сделано
Анимации: CSS-переходы с задержками для поэтапной заливки SVG-сердца, @keyframes, плавные эффекты при наведении
CSS-фильтры на изображениях с длительными переходами
Диалоговое окно на нативном элементе <dialog> с формой
Оптимизация изображений: форматы AVIF и WebP с фолбэком через <picture>
Стили на CSS-переменных, резиновая типографика на clamp(), медиазапрос для мобильных экранов
Вариативный шрифт Inter и пиксельный Press Start 2P для акцентов
Анимации вынесены в отдельный файл animations.css

Скрипт переключения лайка (scripts/like.js) предоставлен в стартовом коде курса; моя часть — вёрстка, анимации и стили.

Стек

HTML5 · CSS3 (анимации, переходы, фильтры, custom properties) · SVG · БЭМ · Git

Как запустить

Откройте демо по ссылке выше или склонируйте репозиторий и откройте index.html в браузере.
